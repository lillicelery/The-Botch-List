# The Botch List

**Find the right surgeon, not just the closest one.**

The Botch List collects real patient reviews of cosmetic surgeons and med spas in New York City from across the web and puts them in one place. You can search, compare, and save providers before booking a consultation. Each provider page includes a short summary of what patients praise and complain about, generated by AI.

Providers can claim their listing and verify it through their business email. They can then manage their profile, see review analytics, and respond to patients.

## Features

**For patients**
- Search providers by procedure, name, or location, and filter by procedure and rating
- Read review excerpts from Google Maps and Reddit, tagged by procedure and sentiment
- See public-record details for every NYC plastic and facial plastic surgeon (NPI number, specialty, NY license, practice address), with a link to the NY State Physician Profile for board certification and disciplinary history
- AI review summaries written by Claude
- Compare providers side by side
- Create an account and save providers

**For providers**
- Claim a listing and verify ownership by email
- Verified badge on the public listing
- Provider portal: review analytics, responses to reviews, and an editable public profile

**Coming soon**
- Paid "Verified Pro" plan for providers (Stripe billing)

## How it works

1. **Collect.** Scripts pull every NYC plastic and facial plastic surgeon from the free CMS NPI Registry, plus listings and reviews from Google Maps, Reddit, and Yelp.
2. **Clean.** Reviews are filtered to cosmetic procedures only, deduplicated across sources, and tagged by procedure and sentiment.
3. **Store.** Everything is imported into a SQLite database.
4. **Summarize.** A script sends each provider's reviews to Claude and saves a 2–3 sentence summary.
5. **Serve.** A Hono API serves the data and handles accounts and claims. The React frontend uses that API.

The app currently serves **New York City**. Providers from other states stay in the database (so the totals still count them) but are hidden from the app. Set `BOTCH_SERVICE_STATES` in `.env` to change this, e.g. `NY,NJ` or `all`.

To refresh the NYC surgeon list (free, no API key): `npm run npi:fetch && npm run npi:import`.

RealSelf was deliberately left out because its robots.txt and terms of service prohibit scraping (see [`scripts/realself/LEGAL.md`](scripts/realself/LEGAL.md)).

## Run it locally

You need **Node.js 20 or newer**.

```bash
npm install
touch .env              # can stay empty; no keys are needed to run the app
npm run seed:demo       # creates demo accounts (printed in the terminal)
npm run dev:all         # API on :8787, app on http://127.0.0.1:5173
```

The provider account opens straight into a working provider portal. Its profile details are sample data.

### Optional keys (`.env`)

The app runs without any keys. Add these only to turn on the matching features:

| Key | Enables |
|---|---|
| `RESEND_API_KEY`, `BOTCH_AUTH_EMAIL_FROM` | Password-reset and claim-verification emails |
| `ANTHROPIC_API_KEY` | `npm run ai:summaries` |
| `APIFY_TOKEN`, `YELP_API_KEY`, `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET` | Data collection scripts |
